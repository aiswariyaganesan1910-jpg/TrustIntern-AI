
# 🛡️ InternShield — Frontend

**InternShield** is an AI-driven platform designed to protect students and job seekers from fraudulent internship offers, phishing scams, and fake employment demands.

---

## 🚀 Key Features

- **Interactive Verification Portal:** Submit company details, recruiter email domains, and offer letter content.
- **Safety Confidence Gauge:** Visual score indicator (0–100%) showing scam probability.
- **Itemized Audit Checks:** Clear pass/fail inspection indicators highlighting red flags (e.g., generic email usage, domain age, monetary demands).
- **Client-Side Fallback Engine:** Built-in heuristic engine ensures continuous operation even if the backend service is offline.

---

## 🛠️ Tech Stack

- **Framework:** React 18 (Create React App)
- **Routing:** React Router v6
- **HTTP Client:** Axios
- **Iconography:** Lucide React
- **Data Visualization:** `react-gauge-chart`
- **Styling:** CSS3 (Modern Dark Slate Glassmorphism Theme)
